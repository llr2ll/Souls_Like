# Souls_Like

Souls-like no navegador, visto de cima: **"O Camiño das Ánimas"** (nome provisório).
Um peregrino no Caminho de Santiago tomado pela névoa. JavaScript + Three.js + Vite, tudo procedural.

```bash
npm install
npm run dev     # jogo na porta 5173
npm run check   # camadas + replay (rodar antes de todo PR)
npm run smoke   # abre o jogo num navegador sem tela e procura erros
```

- `docs/DESIGN.md` — o jogo: conceito, números, área da demo, inimigos, plano de PRs.
- `docs/COMO-FUNCIONA.md` — explicação sem código.
- `docs/TESTE-MANUAL.md` — checklist depois de cada PR.
- `docs/ORIGEM.md` — peças copiadas do survivor (`llr2ll/Zombie_Survivor`) e o que mudou nelas.
- `CLAUDE.md` — memória do projeto para a IA.
